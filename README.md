# ROAD Next-Gen · R&D Research Studio & AI Co-Pilot

> **Report Outline Assistant for Development & AI Research Studio**  
> ระบบออกแบบโครงร่างและเขียนรายงานการวิจัย 5 บท พร้อม AI Co-Pilot และเครื่องมือวิเคราะห์สถิติวิจัยทางการศึกษา สำหรับครู อาจารย์ ศึกษานิเทศก์ และนักวิจัย

## ✨ ไฮไลท์และฟีเจอร์เด่น (Key Features & R&D Methodology)

1. **AI Research Advisor & 10 Pitfalls Validator (หลัก รศ.ดร.ชวลิต ชูกำแพง & วPA ก.ค.ศ.)**
   - **ABCD Pattern Architecture**: แยกแยะประเภทของนวัตกรรม (A: Innovation), หลักการและทฤษฎีพื้นฐาน (B: Principles/Theory), ตัวแปรตามที่วัดได้จริง (C: Outcomes), และกลุ่มเป้าหมาย (D: Target Group)
   - **ระบบตรวจจับข้อบกพร่องในชื่อเรื่องและโครงร่าง (Research Health Score 0–100%)**:
     - *Rule 1*: ห้ามทำประเมินโครงการเพียวๆ สำหรับ วPA
     - *Rule 2*: ห้ามใส่ชื่อย่อ Model ลอยๆ โดยไม่มีหลักการ/ทฤษฎีรองรับ
     - *Rule 3*: ตรวจสอบตัวแปรคลุมเครือ (เช่น "ความเป็นคนดี") บังคับให้เป็นตัวแปรเชิงพฤติกรรม/สมรรถนะ
     - *Rule 4*: ตรวจสอบความสอดคล้องกับระดับวิทยฐานะ (คศ.3–คศ.5 บังคับนวัตกรรมเชิงระบบ/รูปแบบ และ R&D 4 ระยะ)
     - *Rule 5*: ตรวจสอบสมมติฐานการวิจัย (ห้ามตั้งใน R1, D1, D2 ให้ตั้งเฉพาะระยะ R2 ที่มีการทดลองเปรียบเทียบเท่านั้น)
   - **ทิศทางการวิจัยทางการศึกษาของชาติ พ.ศ. 2568–2570**: ครอบคลุม 8 ประเด็นหลัก (Micro-credential, Credit Bank, Green Education, Eco-School 7 Steps, BCG, Digital Citizenship, Learning Loss)
   - **กรอบการประเมิน วPA แยกตาม 3 สายงาน**: สายงานครูผู้สอน (8 ตัวชี้วัด + ผลลัพธ์ 4 ด้าน WEF O*NET), สายงานผู้บริหารสถานศึกษา, และสายงานศึกษานิเทศก์

2. **R&D 4-Phase Operational Matrix & Synthesis Bridge**
   - **ตารางการดำเนินการวิจัย 4 ระยะ (R1 - D1 - R2 - D2) 6 คอลัมน์**:
     `[ขั้นตอนการวิจัย | วัตถุประสงค์ย่อย | การเก็บรวบรวมข้อมูล | แหล่งข้อมูล/กลุ่มตัวอย่าง | ผลที่ได้ | หมายเหตุ]`
   - **ตารางแสดงการเชื่อมโยงจาก R1 สู่ D1 (R1-to-D1 Synthesis Bridge)**:
     อธิบายว่าผลการศึกษาเอกสารทฤษฎีและสภาพปัญหาใน R1 นำไปสู่การออกแบบหลักการ วัตถุประสงค์ และขั้นตอนกิจกรรมของนวัตกรรมใน D1 อย่างไร (ตอบ How & Why ชัดเจน)
   - **โครงสร้างองค์ประกอบของรูปแบบ (Innovation Model Components)**:
     - *สายครูผู้สอน*: 5 องค์ประกอบ (หลักการ, วัตถุประสงค์, กระบวนการจัดกิจกรรม 5–6 ขั้นตอน, สิ่งสนับสนุน, การวัดผล)
     - *สายผู้บริหาร/ศึกษานิเทศก์*: 6 องค์ประกอบ (หลักการ, วัตถุประสงค์, ระบบงานและกลไก, แผนดำเนินงาน, แนวทางประเมิน, เงื่อนไขการใช้)

3. **พิมพ์เขียวรายงานการวิจัย 5 บท (5-Chapter Blueprint Rules) & Word Exporter**
   - **บทที่ 1**: ภูมิหลังเรียง 7 ย่อหน้าแบบกรวยคว่ำ, วัตถุประสงค์ล้อ 4 ระยะ, สมมติฐานเฉพาะระยะ R2, ขอบเขตแยก 4 ระยะ, นิยามศัพท์เฉพาะเชิงปฏิบัติการ (ห้ามนิยามคำทั่วไป)
   - **บทที่ 2**: กรอบแนวคิดการวิจัย (Conceptual Framework) เชิงทฤษฎี `[หลักการ B + นวัตกรรม A] ⟹ [ตัวแปร C]` *(ห้ามวาดเป็นขั้นตอน R1-D2)*
   - **บทที่ 3**: วิธีดำเนินการวิจัยแยก 4 ระยะ ครบ 6 หัวข้อย่อย
   - **บทที่ 4**: ผลการวิเคราะห์ข้อมูลแบ่ง 4 ตอน พร้อมตารางสถิติแบบเส้นขอบมาตรฐานวิชาการ (APA Three-line Table)
   - **บทที่ 5**: อภิปรายผลตามสูตร 4 องค์ประกอบ *(1. ผลพบว่าอะไร 2. เพราะเหตุใดจากกิจกรรมจริง 3. สอดคล้องกับทฤษฎีใคร 4. สอดคล้องกับงานวิจัยใคร)*
   - **Word Exporter (.doc)**: ส่งออกเอกสาร Microsoft Word จัดหน้า A4 ฟอนต์ `Sarabun` ขนาด 16pt พร้อมตารางสถิติมาตรฐาน

4. **Research StatLab Studio & EDURTAP Quality Engine (รศ.ดร.ญาณภัทร & รศ.ดร.ประเสริฐ)**
   - **Statistical Decision Rules**: กฎเหล็กการเลือกสถิติจากวัตถุประสงค์ (ห้ามใช้ t-test กับ E1/E2, กฎ Normality, ANOVA + Post-hoc, Correlation != Causation)
   - **IOC / IC Analyzer**: คำนวณดัชนีความสอดคล้องรายข้อและทั้งฉบับ ($IOC = \sum R / N \ge 0.50$) พร้อมตารางสำหรับบทที่ 3
   - **EDURTAP Test Item Analysis**: วิเคราะห์ความยาก ($p$), อำนาจจำแนก ($r$), Brennan's $B$-Index, KR-20 ($r_{tt}$), และสูตรความเชื่อมั่นของ Lovett (อิงเกณฑ์)
   - **Cronbach's Alpha Analyzer**: คำนวณความเชื่อมั่นแบบสอบถามมาตราส่วนประมาณค่า ($\alpha \ge 0.80$) และค่าความแปรปรวนรายข้อ ($S_i^2$)
   - **Innovation Efficiency ($E_1/E_2$) & Effectiveness Index ($E.I.$)**: คำนวณและแปลผลเทียบเกณฑ์มาตรฐาน (80/80, 75/75, 70/70)
   - **t-test & Cohen's d (Effect Size)**: คำนวณ Dependent samples t-test และขนาดอิทธิพล Cohen's $d$ ($d \ge 0.80$ Large Effect)

5. **Dual-Mode AI Co-Pilot & Academic Ecosystem Guide**
   - Smart Prompt Builder 6 ภารกิจ (ที่มา 7 ย่อหน้า, ตารางเชื่อมโยง R1->D1, เกลาชื่อเรื่อง ABCD, นิยามศัพท์เฉพาะ, กรอบทฤษฎีบทที่ 2, อภิปรายผล 4 องค์ประกอบ)
   - รองรับ Google Gemini API สั่งเขียนสดในเว็บทันที
   - Academic AI Guide: Consensus, Perplexity AI, Claude 3.5 Sonnet, Zotero, Grammarly, ThaiJO / TCI Journal Finder

## 🚀 การเริ่มต้นใช้งานในเครื่อง (Local Setup)

### วิธีที่ 1: รันผ่าน Batch script (แนะนำ)
ดับเบิลคลิกไฟล์:
```bat
start-road.bat
```

### วิธีที่ 2: รันผ่าน Node.js
```bash
# ติดตั้ง dependencies (โปรเจกต์ใช้ Built-in Node modules ทั้งหมด)
npm start
```
เปิดเบราว์เซอร์เข้าที่:
* **Studio**: [http://localhost:3080/app?welcome=1](http://localhost:3080/app?welcome=1)
* **Login**: [http://localhost:3080/login](http://localhost:3080/login)
* **Admin**: [http://localhost:3080/admin](http://localhost:3080/admin)

### วิธีที่ 3: เปิดตรงผ่านไฟล์ HTML (Offline / Standalone)
สามารถดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ใดก็ได้โดยไม่ต้องรันเซิร์ฟเวอร์

## ☁️ การ Deploy บน Vercel

โปรเจกต์นี้ได้รับการตั้งค่า `vercel.json` สำหรับการ Deploy แบบ Static SPA เรียบร้อยแล้ว:
```bash
vercel deploy --prod
```
หรือเชื่อมต่อ repository นี้กับ Vercel Dashboard ได้ทันที
